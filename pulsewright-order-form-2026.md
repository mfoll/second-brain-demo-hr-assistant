# Pulsewright Order Form 2026

The one-year order form and data processing schedule with Pulsewright for calendar year 2026, signed in February 2026.

## Summary

Licence for up to 4,500 participants, unlimited surveys, manager dashboards for up to 60 users, translation of up to six languages. Ends 2026-12-31 unless renewed.

## Key Details

- Data processing schedule: data held in the supplier's European data centres; raw responses deleted 24 months after each survey closes; supplier staff access only for support with our permission.
- Reporting threshold configurable per survey; default 5.
- Support: named account manager ([[owen-tremaine]]), two-working-day response for standard tickets.
- Price held by [[theo-varkey]]; not recorded here.
