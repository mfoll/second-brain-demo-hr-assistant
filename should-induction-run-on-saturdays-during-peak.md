# Should Induction Run On Saturdays During Peak?

## Question

Should we run a Saturday hub induction on 2026-11-14 for the final peak intake, so late hires can start on Monday 2026-11-16 instead of a week later?

## Current State

Open; decision needed by 2026-11-02 to book trainers.

## For

- The last weekday sessions are on 2026-11-09 to 2026-11-12. Anyone cleared after that would otherwise miss peak preparation.
- [[maeve-donnelly]] and [[conrad-baptiste]] support it if it does not cost a weekday shift.

## Against

- Trainers and the safety trainer would need overtime or time off in lieu; two of the four hub trainers have said no.
- Starters inducted on Saturday must still be in Talvento by Thursday 12:00 of their first week; a Saturday induction does not change that.
- If agency covers the gap ([[how-do-we-close-the-peak-hiring-gap]]), the agency's workers can join weekday sessions.

## My lean

One Saturday session at Hub East only, for all hubs, if the final shortfall is above 20. Otherwise not worth it.
