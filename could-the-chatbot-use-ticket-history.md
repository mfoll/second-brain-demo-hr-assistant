# Could the Chatbot Use Ticket History?

The vendor suggested in May 2025 that Deskwell Assist would answer better if it could read past tickets and replies.

## Current Answer

No. [[kasia-wrobel]] ruled it out on 2025-05-22: tickets contain employees' personal details, sometimes health and family circumstances, and using them to answer other people's questions is a new purpose that the helpdesk was never set up for. The bot reads published articles only ([[deskwell-assist-trial-terms]]).

## Why it stays answered

The same reasoning as [[data-minimisation]] and the case pointer rule ([[record-hr-cases-without-personal-data]]). It also applies to my [[diploma-research-project]], which uses monthly counts by category, never ticket text.

## Revisit if

Only if a future proposal used anonymised themes written by people, as I did for the [[chatbot-test-question-set-2025]], rather than ticket text. That would need Kasia's review again.
