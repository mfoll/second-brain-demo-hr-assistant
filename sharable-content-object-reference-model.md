# Sharable Content Object Reference Model

## Summary

SCORM is a collection of standards and specifications for web-based e-learning. It defines how course content in the browser talks to the host system, usually an LMS, and how content is packaged as a ZIP file (the Package Interchange Format) so it can move between systems.

## Why It Matters

I looked it up when the Data Protection Essentials test kept timing out on the Hub West kiosks ([[hub-training-kiosk-pilot-results]]). Our packages are SCORM 1.2, and completion depends on the package reporting its status back to [[learnmoor]]; if the session drops before that, the person has done the course but the record says otherwise. That is now the first thing I check when someone says "I did it" ([[learnmoor-report-quirks]]).

## Caveats

The article describes the standard, not how Learnmoor implements it.
