# Hub Induction Day Running Order

The standard timetable for the [[hub-induction-day]], version 3, used at all four hubs from 2026-09-07.

## Summary

A seven-hour day, 08:30 to 15:30, for up to 40 starters (32 at Hub West). Morning in the training room and on the safety walk-round, afternoon with a team leader on the floor.

## Key Details

| Time | Slot | Led by |
|---|---|---|
| 08:30 | Welcome, ID badges, site rules | Hub trainer |
| 09:00 | Safety briefing and walk-round, two groups of up to 20 | Safety trainer |
| 10:45 | Break | |
| 11:00 | Systems and pay: Talvento app log-in, rota, first pay date, who to ask | People Services |
| 11:45 | Mandatory courses enrolled in Learnmoor, first module done | Hub trainer |
| 12:30 | Lunch | |
| 13:00 | Team leader time on the floor, buddying with an experienced operative | Team leader |
| 15:00 | Questions and feedback form | Hub trainer |
| 15:30 | Finish | |

## Why It Matters

The single shared version that replaced four hub-specific inductions. The systems slot is where People Services catches anyone whose [[new-starter-data-form]] is missing.

## Caveats

Hubs still differ in details such as locker allocation and canteen passes ([[hub-induction-differences-by-hub]]).
